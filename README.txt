HexaCase 1.0.0 — кейсы с выбором сундука (Purpur 26.3, Bedrock через Geyser)

КАК СОБРАТЬ (нужен компьютер)
1. Установите Java 21 или новее и Maven.
2. В папке с pom.xml выполните:  mvn package
3. Готовый плагин: target/HexaCase-1.0.0.jar
4. Положите jar в папку plugins сервера и перезапустите сервер.
   Сначала проверьте на тестовом сервере, а не на основном.

ПРАВА (только owner)
В LuckPerms (замените owner на название вашей группы):
  /lp group owner permission set hexacase.admin true

КОМАНДЫ (только с правом hexacase.admin)
  /case give <ник> <кейс> [число]   выдать кейсы игроку
  /case count <ник>                 сколько у игрока кейсов
  /case setblock                    привязать блок, на который смотрите, к меню кейсов (спавн)
  /case removeblock                 отвязать блок
  /case list                        список кейсов
  /case reload                      перезагрузить config.yml

КАК ЭТО РАБОТАЕТ
- Игрок бьёт/нажимает на привязанный блок на спавне и видит меню со своими кейсами.
- Клик по кейсу: вокруг появляются сундуки, 30 секунд на выбор (таймер в конфиге).
- Нажатие на сундук: награда выдаётся сразу, над остальными сундуками на 6 секунд
  показываются их награды, забрать их нельзя. Потом сундуки пропадают, блоки возвращаются.
- Не выбрал за 30 секунд или вышел с сервера: выдаётся случайная награда.
- Данные игроков: plugins/HexaCase/data.yml

НАСТРОЙКА (plugins/HexaCase/config.yml)
- Шансы в privilege ЧЕРНОВЫЕ, поменяйте под себя.
- Деньги в free-кейсе: замените команду eco give на команду вашей экономики.
- skip-if-permission: если у игрока уже есть этот ранг или выше, ранг не выдаётся,
  а выполняется fallback-commands.
- Император выдаётся на 30 дней: lp user {uuid} parent addtemp imperator 30d
